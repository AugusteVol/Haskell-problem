# Haskell problem

## Problem
Given an integer n ≥ 1 and an integer p ≥ 1 you are to write a program that determines √n p, the positive n-th root of p. In this problem, given such integers n and p, p will always be of the form k^n for an integer k (this integer is what your program must find).

Problem is taken from:
https://onlinejudge.org/index.php?option=com_onlinejudge&Itemid=8&category=3&page=show_problem&problem=49
(Problem file is also inside the project as a pdf)

# How to run
1. Open Program.hs
2. Open terminal
3. Type "runghc Program.hs"
